# Student Compass

## Overview

Student Compass is a web application that helps first-year students
understand their degree, semester roadmap, skills, and career direction.

## Problem

New students often lack a clear understanding of their academic journey,
required skills, and career planning.

## Solution

Student Compass provides a simple dashboard with: - Semester roadmap -
Daily and weekly learning tasks - Progress tracking - Learning
resources - Responsive design - Personalized welcome using Local Storage

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Local Storage

## Project Structure

- index.html -- Login/Get Started
- cse.html -- Dashboard
